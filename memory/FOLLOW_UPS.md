## ~Open — Claim a permanent `g.page/r/...` Google review short link

**Set:** June 28, 2026
**Trigger:** Next time the GigLine Google Business Profile is open in a browser tab

**Why this matters:** `maps.app.goo.gl/...` URLs get regenerated by Google whenever you re-share from the mobile app or the Google Maps web UI. This has already forced 3 sitewide URL swaps in a single session (touching backend `.env` + 5 frontend files each time). The `g.page/r/...` format is the only Google review URL that's guaranteed permanent.

**Steps (5 minutes):**
1. Open https://business.google.com → select GigLine Safety & Compliance profile
2. Click **"Get more reviews"** (sometimes labeled "Ask for reviews")
3. Click **"Share review form"**
4. Click **"Get a short URL"** — Google will generate a `g.page/r/<random>/review` link tied permanently to this profile
5. Paste it in chat — Emergent will swap the 6 sitewide surfaces one last time, and the swap-cycle ends

- `backend/.env` → `GIGLINE_GOOGLE_REVIEW_URL` (Safety Check PDF generator)

- `SupervisorKitThankYouPage.js` (kit thank-you panel)
